# LogicGatesSandbox
Jogo 2D sandbox feito em C# na Unity. O objetivo é disponibilizar as 3 portas lógicas principais AND, NOT e OR, e permitir o usuário criar o que quiser com elas. O intuito do jogo é ajudar no estudo da base da computação, além das portas lógicas haverá vários exemplos de circuitos, e textos explicativos sobre portas lógicas e principais circuitos.
